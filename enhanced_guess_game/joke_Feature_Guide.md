# 😄 Joke Feature Guide

## What is it?

A fun alternative to guessing! If you're stuck, you can tell Gemini a joke instead of making a numerical guess.

## How it Works

### 1. When to Use Jokes
- You're unsure about your next guess
- You want to take a fun break
- You're feeling creative!
- Any time during normal gameplay (not during tiebreakers)

### 2. How to Tell a Joke

Simply type your joke in the **Gemini AI chat box**. Include words like:
- "Here's a joke..."
- "Wanna hear something funny?"
- "Knock knock..."
- Or just tell the joke naturally!

**Examples:**
```
"Why was 6 afraid of 7? Because 7 8 9!"

"What do you call a number that can't sit still? A roamin' numeral!"

"Knock knock. Who's there? Math. Math who? Math-ter of fact, I don't know!"
```

### 3. Joke Evaluation

Gemini evaluates your joke based on:
- ✅ **Has a clear setup/punchline** (Question? Answer!)
- ✅ **Reasonable length** (At least 6 words)
- ✅ **Good structure** (Uses punctuation effectively)
- ✅ **Not repeated** (Must be unique in this session)

### 4. What Happens Next?

#### If Your Joke is Funny 😂
```
✅ Counts as CORRECT guess
💰 Earn points (same as correct guess)
✨ Get +1 bonus trial
🔥 Streak continues
🎮 New round starts automatically
```

#### If Your Joke Needs Work 😐
```
❌ Counts as INCORRECT guess
⚠️ Uses one trial
💡 Get constructive feedback
🎯 Keep playing (if trials remain)
```

#### If You Repeat a Joke 🔄
```
🚫 Doesn't count as a guess at all
💬 Get a friendly reminder
✨ No trial used
🎭 Try a different joke!
```

## Tips for Great Jokes

### Good Joke Structure
```
Setup → Build → Punchline

Example:
"Why don't scientists trust atoms?"
[pause for effect]
"Because they make up everything!"
```

### Math-Themed Jokes (Bonus points for creativity!)
```
"Parallel lines have so much in common...
It's a shame they'll never meet!"

"Why should you never talk to Pi?
Because it'll go on forever!"

"What's a math teacher's favorite vacation spot?
Times Square!"
```

### What Makes Jokes Work
- **Surprise element**: Unexpected punchline
- **Wordplay**: Puns and double meanings
- **Clear delivery**: Good punctuation and spacing
- **Appropriate length**: Not too short, not too long

### What to Avoid
- ❌ One-word responses
- ❌ Jokes you've already told
- ❌ Very offensive content
- ❌ Just random statements without humor
- ❌ Too complex or confusing setups

## Strategy

### When Jokes Are Strategic

**Low on trials?**
```
Trials left: 1
Confidence in next guess: Low
→ Tell a joke! 50% chance vs. uncertain guess
```

**Building a streak?**
```
Current streak: 2
Next guess: Risky
→ Try a joke to maintain momentum!
```

**Just for fun!**
```
Sometimes the best strategy is to enjoy the game!
Laughter counts too! 😄
```

### When to Just Guess

**High confidence?**
```
Range narrowed to 3-5 numbers
→ Make your numerical guess
```

**Lots of trials remaining?**
```
Trials: 7 remaining
→ Play normally, save jokes for emergencies
```

## Database Tracking

All jokes are saved with:
- Joke text
- Funny rating (yes/no)
- Whether repeated
- Gemini's response
- Whether accepted as guess
- Timestamp

This ensures:
- No repeated jokes in your session
- You can review your joke history
- Stats track joke success rate

## FAQ

**Q: Can I tell multiple jokes in one turn?**
A: Each joke counts as one guess attempt.

**Q: Do jokes work during tiebreakers?**
A: No, tiebreakers require mathematical answers.

**Q: What if my joke is inappropriate?**
A: Keep it family-friendly! Offensive jokes won't count.

**Q: Can I edit my joke after sending?**
A: No, once sent it's evaluated. Make it count!

**Q: Do jokes affect my accuracy stats?**
A: Yes! Funny jokes count as correct, unfunny as incorrect.

**Q: Can I see my joke history?**
A: It's stored in the database. Check game history!
